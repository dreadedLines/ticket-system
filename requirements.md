# Requirements

## User Stories

### US-01 Event List

As a customer,
I want to view available events,
so that I can choose an event to attend.

### US-02 Event Details

As a customer,
I want to view event details,
so that I can understand the event before purchasing a ticket.

### US-03 Search Events

As a customer,
I want to search for events,
so that I can quickly find an event.

### US-04 Select Ticket

As a customer,
I want to select a ticket,
so that I can reserve my preferred ticket.

### US-05 Reserve Ticket

As a customer,
I want to reserve a ticket,
so that the ticket is held for me.

### US-06 Payment

As a customer,
I want to pay for my reservation,
so that I can complete my ticket purchase.

### US-07 Electronic Ticket

As a customer,
I want to receive an electronic ticket,
so that I can enter the event.

### US-08 Reservation History

As a customer,
I want to view my reservation history,
so that I can manage my tickets.
